# Changelog

## [1.0.0](https://github.com/hzgcoding/breeze/releases/tag/v1.0.0) (2026-10-21)

- Establish Breeze as an independent product with a new name, wind mark, repository, package namespace and release artifacts.
- Redesign the request editor with teal and graphite surfaces, consistent section headers, monospace fields and light/dark themes.
- Keep existing profile storage and version 1/2 exchanges compatible, including current-session tab bindings.
- Share profiles through the independent documentation site using local fragment decoding, strict URL validation and a JSON fallback.
- Replace external documentation search and unrelated store/support destinations with local search and Breeze resources.
- Add fixed-directory local builds with dependency-first asset synchronization and retained resources for open pages.
